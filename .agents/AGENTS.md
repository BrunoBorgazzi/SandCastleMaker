# Reglas del Proyecto SandCastleMaker

- **Cuidado con los repositorios anidados:** Si al hacer comandos de Git el nombre del repositorio no coincide con la carpeta en la que estamos trabajando o se detecta un repositorio anidado, siempre preguntar al usuario qué hacer antes de subir los cambios.
- **Privacidad de herramientas:** Las herramientas de Editor creadas para automatizar la UI (`Assets/Scripts/Editor/`) deben mantenerse privadas y excluidas del repositorio (ignoradas en `.gitignore`).
